# 项目执行约定

- 执行命令、读写、验证只通过 exec 工具。
- 长期业务基准是 背景文件/BIZ-RULES-FULL.md；会话新决定记录于 specs/decisions.md，不能用旧代码覆盖用户需求。
- 使用 Spec Kit：章程 → 规格 → 规划 → 任务 → 一致性分析 → 实施和检查。用户已授权连续推进各阶段，不需每阶段再询问。
- 所有六部门业务须进入规格和覆盖表，优先实现已确认的推文闭环。
- 自动归档是核心：正常完成必须自动归档；强制关闭不自动生成工时。
- 教师、外部用户不计工时；两位运营部长任一确认可送老师一审，一二审由不同老师负责。兄弟组织新闻稿先通过采编内容审核。
- 工时特殊调整允许，但留原因、原值、核定值、操作者和时间；已封存快照不变。
- 两端共享关系型后端；禁止客户端直写核心业务表或自报角色。
- 旧小程序只读参考，不直接重置或迁移其生产数据。未接通的微信等外部服务必须明确标识。
