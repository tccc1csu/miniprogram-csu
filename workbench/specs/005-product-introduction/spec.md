# Feature Specification: 登录前产品介绍页

**Feature Branch**: 无（当前目录未使用 Git）
**Created**: 2026-11-26
**Status**: Ready
**Input**: 登录前新增精致的产品介绍页，参考网易 UU 远程官网；登录放左上，约占首屏四分之一，结合工作台截图让新用户知道怎么使用。

## User Scenarios & Testing

### User Story 1 - 了解产品并登录 (Priority: P1)

首次访问者无需登录即可了解产品，并从左上方直接登录。
**Independent Test**: 清除会话访问首页，阅读首屏并输入既有账号登录。
**Acceptance Scenarios**:
1. 未登录打开首页时，呈现品牌、产品介绍和左上方登录区域；桌面登录列宽约为可用首屏宽度的四分之一。
2. 正确登录进入原工作台或原待访问任务；错误凭据显示错误并允许重试；退出回到介绍页。

### User Story 2 - 从真实界面了解功能 (Priority: P1)

访问者通过示例截图和可切换功能介绍，了解任务、审校、归档与工时。
**Independent Test**: 切换产品展示，确认相应界面与介绍匹配。
**Acceptance Scenarios**:
1. 截图仅使用隔离的演示数据，清楚标注示例，不公开真实成员、任务或账目。
2. 页面涵盖六部门协作、稿件批注、老师两审、自动归档、工时核定及 Excel 导出。
3. 不将尚未接通的微信机器人或云服务描述为已可使用。

### User Story 3 - 知道自己的下一步 (Priority: P2)

需求方、干事、部长、老师和办公部能找到自己的首次使用路径。
**Independent Test**: 切换角色指引，确认每种身份有具体步骤，且可回到登录。
**Acceptance Scenarios**:
1. 包含从提交需求到归档核算的简明流程，以及角色对应操作和常见问题。
2. 小屏幕自动改为单列，表单、导航和指引均可触达；键盘可以操作交互，减少动态效果偏好得到尊重。

### Edge Cases

- 已登录访问者继续看到工作台，不被介绍页打断。
- 未登录访问任务深链接，登录后保留任务路由；介绍页导航不能污染工作台 hash 路由。
- 网络失败时保留输入并提示；演示入口只在原有本地条件成立时显示。
- 截图加载失败仍有文本说明；无真实微信登录、扫码或未实现下载入口。

## Requirements

### Functional Requirements

- **FR-001**: 未登录显示介绍页，桌面左上登录区域约占首屏宽度四分之一，移动端单列。
- **FR-002**: 复用既有账号登录、错误、提交中、退出和深链接行为，本地演示入口保留且生产不展示。
- **FR-003**: 用可切换示例截图解释任务、审校和工时报表，并说明自动归档及六部门业务。
- **FR-004**: 提供完整简明流程、各角色首次使用指引和常见问题。
- **FR-005**: 页面内导航、切换、返回登录均可用，支持键盘、可见焦点和减少动态效果。
- **FR-006**: 宣传信息忠于已实现业务，示例与真实数据区分；不对未接入微信能力作上线承诺。

### Key Entities

仅公开静态介绍内容和隔离示例截图，不新增业务实体。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 在 1440px 桌面首屏可直接找到账号、密码和登录按钮，无需额外点击进入表单。
- **SC-002**: 在 390px 手机、768px 平板、1440px 桌面页面无横向溢出；三种功能和五种身份的介绍均可操作。
- **SC-003**: 正确登录、错误提示、退出、任务深链接四种行为通过浏览器验证。
- **SC-004**: 所有公开截图均由隔离演示库生成，未接入服务表述与现状一致。

## Assumptions

- “四分之一”解释为桌面首屏左侧登录列约占布局宽度四分之一；小屏以可读和可操作为先。
- 采用现有品牌的深绿、暖白，辅以明亮橙色；参考官网的留白、大标题和产品展示节奏，不复制其商标素材。
- 本次本机交付，不重新发布尚未连通数据库的云端服务。
