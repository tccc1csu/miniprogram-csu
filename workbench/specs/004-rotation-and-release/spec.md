# 工时备注、按单轮值与两端联动

长期业务基准见 `背景文件/BIZ-RULES-FULL.md`。本规格以最新会话决定覆盖时段轮值。

- FR-001 任意类型任务可留任务备注。发起人、当前承接人和承接部门管理人员可补充，历史留痕。
- FR-002 核定工时时记录原因，规则及核定有差值时保留实际导致差值的原因。系统加急显示倍数。Excel 导出任务备注和工时核定备注，旧封存原样保留，新封存保存两列内容。
- FR-003 部门管理人员配置有序名单。后续任务进入可派发环节时，由名单依次自动承接，到末位循环。无有效轮值成员时待手动派发。
- FR-004 每个流程已配置的默认承接人优先，任务退回不重新轮值。部长在首次交付前可改派。摄制无自动承接时仍可抢单。推文自动派发需要已有有效审校组合。
- FR-005 通过用户指定的腾讯云 CloudBase 环境提供可访问的工作台，生产数据和附件持久保存。
- FR-006 小程序共享工作台账号与 API，可提需求、提交供稿和附件并查看进度。旧文档数据可通过独立映射核对历史，按授权分阶段切换。
- FR-007 当前 CloudBase 共享 PostgreSQL 通过官方 HTTPS 数据接口接入。两端继续调用工作台业务 API，客户端不持服务端 API Key，不直写核心表；账号和六部门所有数据路径均须适配。
- FR-008 关键写入通过单次数据库业务函数完成。派发、审核、完成归档计时、调整、封存与通知写入保持各自事务，并发加锁，以 request_id 和请求摘要去重。
- FR-009 附件与归档成品保存到 PG 模式私有云存储，PG 保存稳定文件标识与校验信息。上传和业务登记使用可补偿确认流程，不依赖云容器磁盘。
- FR-010 迁移须有一致逻辑备份、来源映射、去重、附件校验和工时金额对账。历史归档不重放工作流重算，封存快照按原值保留。
- FR-011 网页可访问和数据库健康分别验收。正式健康接口执行受控数据库查询，公开响应不泄漏连接地址、凭据和内部错误详情。
- FR-012 可靠云端定时触发消费 outbox，支持缩容到零后的补偿、去重和重试；机器人未配置时明确显示未接通。
- FR-013 按用户新决定向云端补充带验收标识的代表性数据，覆盖六部门、原有角色、主要流程阶段、附件、调整备注和封存报表。写入前备份；正式账号和旧小程序库保留。导入可重复执行且不重复造数、不重置验收进度；测试账号可从公开 HTTPS 登录。此数据不作为真实历史结算依据。

验收包括真实 XLSX 与快照、连续及并发轮值、权限、公开 HTTPS、同一任务在小程序与 Web 可见。
