# 云端角色与业务验收指引

访问 [青年传媒中心工作台](https://youth-media-workbench-352447-7-1459171011.sh.run.tcloudbase.com)。腾讯测试域名首次访问可能显示平台提示，点击“确定访问”。本机可以关闭，前端、业务服务、数据库、附件和调度均在云端。

本轮按用户要求生成可操作的代表性数据：**21 个测试账号、47 个任务、14 种流程状态、38 条工时、28 份附件、1 份封存报表**。所有任务标题带“【验收】”，原说明也保留数据集标识。它们用于测试和验收；金额及示例发布链接不代表真实业务。

## 建议的验收路线

| 要检查什么 | 登录和操作 |
| --- | --- |
| 先看全貌 | `demo-admin` 打开任务中心、成果档案与工时报表 |
| 外部来稿先过采编 | `external` 找“社团嘉年华｜等待供稿”交稿；`editor` 内容审核；`minister` 再安排排版 |
| 供稿退回 | `external` 打开“劳动教育月｜供稿补充材料”，看意见并补稿 |
| 排版及任一部长内审 | `member` 处理“校运会｜排版待交稿”；`minister` 或 `minister2` 审核新版本 |
| 文中批注 | `teacher` 打开“逛一所校园｜秋日影像志”，已有一条精确批注；可以选中文字再批注 |
| 两位老师分别审 | `teacher2` 处理“研途盲盒｜毕业条件指南”；一审账号不能替代二审审批 |
| 修改后留版本 | `member` 打开“迎新专题｜按批注修改”，按老师意见重交，旧版本和意见保留 |
| 发布自动归档 | `member` 处理“志愿服务月｜等待发布”，填有效发布链接，查看档案和新增内部工时 |
| 挂网与推文联动 | `office2` 看挂网案例；“校园文化节｜挂网关联推文”可追溯已归档的挂网任务 |
| 固定承接 | `office` 在流程设置看办公挂网默认 `office2`；已有“固定对接”自动分配案例 |
| 按单轮值 | `photo` 看流程设置：`photo2 → photo3 → photo2`；两条“顺序轮值”已依次分配，下单会继续轮转 |
| 摄制抢单和加急 | `photo2` 处理“讲座摄影｜可抢单”；“晚会摄制｜加急完成”含加急说明和创作工时倍数 |
| 美编三种复杂度 | `art` / `art2` 看基础、复杂、大型设计的交付、退回和归档案例 |
| 原创人工登记 | `original2` 查看原创归档和关联补登记；`original` 核定工时 |
| 强制关闭不计时 | 看“活动取消｜强制关闭”，归档原因保留，自动工时为零 |
| 核定原因和 Excel | `office` 看全中心报表，规则值、核定值、任务备注、工时核定备注均可导出 |
| 封存不随修改变化 | “本期工时封存样例”已封存；一条运营创作工时在封存后又补计 0.5h，旧封存仍保留原值 |
| 兄弟组织报名 | `external2` 查看“联合团支书培训会｜待安排”的已报名记录 |

教师和外部组织有参与记录，但无法进入工时报表。干事只看自己的工时，部长核定本部，办公部长可查看全中心。

## 数据维护与验证

`npm run db:seed:acceptance` 是显式的云端造数命令。写入前后均有本机完整备份和恢复检查。数据集已存在时直接跳过，重复运行不会新增账号或任务，也不会恢复你已经推进的环节。首次导入遇到已有同名账号或已配置路由会拒绝，避免覆盖真实资料。生产启动不会自动播种这些数据。

`npm run test:cloud:acceptance` 已通过 8 项公开云端检查，逐一验证 21 个账号、全部初始任务阶段、权限、工时、Excel、封存、28 份附件和真实浏览器。该检查保留业务，只清理自身登录会话；你推进业务之后，初始状态断言发生变化是预期现象。

导入、重复执行和公开验收证据分别见 `artifacts/cloudbase/acceptance-import.json`、`acceptance-rerun.json`、`acceptance-public.json`；页面截图和报表样本位于同目录。导入前后数据库及附件备份在 `.data/backups`。

旧小程序生产库没有修改。微信机器人真实群发尚未配置；小程序合法域名和真机发布仍需按部署指引完成。
