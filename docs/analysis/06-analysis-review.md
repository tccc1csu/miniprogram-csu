## 边界与假设

- 不变更 SRS／SDD／STD，不改小程序代码。类图是分析模型，不代表现有数据集合或实现架构。
- 公共身份、部门资格在分析序列图中展开为成员职责；并未扩大任何未授权角色的实际权限。
- 运营推文阶段的状态图只依据目前清楚的一审、二审责任；其他部门的一审岗位保持待确认。
- 沿用通用流转规约中的阶段确认与最终归集方案，该方案仍需业务评审。
- 摄制冲突资源口径、两天计法及加急适用贡献尚未确认，摄制约定和津贴标准分别封装其判断依据，不新增数值。
- 同一实际贡献在专门任务与流转阶段之间需保持来源关联；来源、贡献类型和成员组成业务去重依据，不把分析对象标识映射成数据库主键。
- 界面边界是职责抽象。登录和预约供三个角色共同使用，图中的普通成员接口代表共同成员入口，不用于推导角色拒绝规则。
- 已归档仍可查询，故未绘最终消亡节点；不人为添加取消、撤销归档、补发津贴等未提出的状态。
