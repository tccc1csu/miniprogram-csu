# 软件测试文档（STD）框架

版本：0.1-draft  
系统：青年传媒中心工作统计与协作小程序

## 1 测试目标与范围

验证 SRS 中的功能需求、非功能需求、角色权限、状态迁移、统计计算和数据隔离；同时建立每次独立功能开发后的最小回归集。测试以微信开发者工具、云函数测试和必要的真实微信端验证为主。

## 2 测试策略

| 层级 | 内容 | 责任 |
| --- | --- | --- |
| 单元/函数 | 规则计算、状态迁移、字段校验、权限判断 | 开发者 |
| 接口 | 云函数 action、鉴权、错误码、幂等 | 开发者/测试者 |
| 集成 | 页面 -> db.js -> 云函数 -> 数据库 | 测试者 |
| 系统 | 角色完整流程和跨模块数据联动 | 测试者/业务负责人 |
| 回归 | 认证、周记录、周报、协同、管理核心链路 | 每次发布 |
| 可用性 | 移动端表单、空状态、错误提示、导出结果 | 测试者 |

## 3 测试环境与数据

- 测试环境：独立云环境或明确标记的测试数据集。
- 测试账号：管理员、各流程部长、普通成员，密码和 openid 不得使用生产值。
- 数据集：至少 3 个部门、每部门 2 名成员、当前周和历史周记录；每名成员至少 2 条任务明细和 1 条周汇总；采编协同、摄制预约各状态至少 1 条。
- 测试后清理：使用 `seedTag` 清理演示数据，不直接清空生产集合。

## 4 测试套件与核心用例

### TS-AUTH-001 认证与权限

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| TC-AUTH-001-01 | 正确账号密码登录 | 返回会话并进入对应角色首页 |
| TC-AUTH-001-02 | 错误密码/不存在账号 | 返回明确错误，不建立会话 |
| TC-AUTH-001-03 | 过期 token 调用业务接口 | 请求被拒绝并提示重新登录 |
| TC-AUTH-001-04 | 成员调用管理员管理动作 | 返回无权限且数据不变 |
| TC-AUTH-001-05 | 注册重名、非法角色或部门 | 校验失败，不写入半成品数据 |

### TS-ORG-001 组织与人员

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| TC-ORG-001-01 | 管理员新增/编辑/停用部门 | 列表和关联选择同步更新 |
| TC-ORG-001-02 | 部长查看成员 | 只能看到本部门成员 |
| TC-ORG-001-03 | 删除有记录成员 | 按产品规则阻止删除或保留历史关联 |

### TS-REC-001 工作记录与统计

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| TC-REC-001-01 | 归档一项采编任务 | 生成一条采编/办公同步任务明细，并进入相关成员周汇总 |
| TC-REC-001-02 | 同一任务重复归档 | 不生成第二条任务明细，周汇总结果不变 |
| TC-REC-001-03 | 摄制预约归档 | 摄制干事和指定归档成员各生成一条任务明细 |
| TC-REC-001-04 | 同成员同周多条任务明细 | 周汇总按明细合计，只有一条周汇总记录 |
| TC-REC-001-05 | 会议规则版本变更 | 新规则只影响新归档或新计算，历史明细保留旧版本 |
| TC-REC-001-06 | 周报文本和 CSV 导出 | 字段、明细汇总、编码和换行可用 |

### TS-COL-001 协同流转

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| TC-COL-001-01 | 采编部提交稿件需求 | 创建为待办公部派发，稿件字段完整且仅相关角色可见 |
| TC-COL-001-02 | 办公部部长派发 | 状态变为待干事同步，责任人、DDL 和提醒正确 |
| TC-COL-001-03 | 办公部干事完成同步 | 状态变为待管理员审核，平台、链接和反馈被保留 |
| TC-COL-001-04 | 管理员审核通过 | 自动变为已归档，生成两类任务明细且不重复 |
| TC-COL-001-05 | 管理员退回修改 | 状态变为退回修改，干事重新提交后回到待管理员审核 |
| TC-COL-001-06 | 非法越级或重复归档 | 请求被拒绝，原状态和任务明细不变 |

### TS-COL-001-07 摄制预约归档

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| TC-COL-001-07 | 摄制部部长派发并指定归档成员 | 摄制干事完成后状态变为待办公部归档 |
| TC-COL-001-08 | 指定办公部成员归档 | 摄制干事和归档成员工时均自动进入任务明细 |
| TC-COL-001-09 | 摄制预约加急阈值 | 按会议确定的阈值标记加急，倍率来自规则版本 |

### TS-INFO-001 信息工具

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| TC-INFO-001-01 | 通讯录增删改查 | 权限正确，联系方式展示和复制可用 |
| TC-INFO-001-02 | 提交建议并审核 | 未审核建议不进入公开投票 |
| TC-INFO-001-03 | 重复投票 | 同一用户对同一主题只能成功一次 |
| TC-INFO-001-04 | 活动通知 | 目标部门可见，站内通知可追踪 |
| TC-INFO-001-05 | 任务提醒未授权 | 站内通知仍可用，不阻塞业务流程 |

## 5 非功能测试

- 性能：使用演示规模数据测试首页、记录、统计和协同列表响应时间。
- 安全：测试越权读取、越权写入、伪造角色、过期会话和敏感字段泄露。
- 可靠性：重复点击、网络重试和并发提交不产生重复记录或非法状态。
- 可用性：测试移动端长文本、空列表、错误恢复、导出编码和不同屏幕宽度。
- 兼容性：微信开发者工具、至少一种真实 iOS/Android 微信环境。
