# 学生组织工作统计小程序

本项目是为某高校学生组织（青年传媒中心）日常工作开发的小程序，作为微信云开发（CloudBase）全栈实践示例开源。本项目为微信云开发版本，不需要启动本地 Node/SQLite 后端。

> 📘 **接手本项目？** 请先阅读 [HANDOVER.md](./HANDOVER.md)，其中说明了环境配置、恢复步骤和已知踩坑记录。

- AppID：`YOUR_WECHAT_APPID`（请替换为你自己的小程序 AppID）
- 小程序前端：`miniprogram/`
- 统一云函数：`cloudfunctions/api/`

## 已整合功能

- 微信授权登录：已绑定账号可一键登录，登录态默认保留 14 天。
- 账号密码登录：任意账号均可用姓名和密码在当前设备切换登录，不会改变已有微信绑定；注册成功后仍会绑定当前微信。
- 第一位正式管理员可自助注册；测试管理员账号不会占用正式管理员名额。
- 普通成员可自行上报每周工作类型、工作内容和工时。
- 工作量类型固定为：稿件写作、视频制作、美编设计、日常办公。
- 部长批量维护本部门成员每周工作内容和工作量。
- 上传页显示已填写人数和总工作量，并支持一键清空草稿。
- 管理员首页显示部门排名。
- 记录页支持管理员按部门筛选。
- 周报表格支持复制文本周报和 CSV 数据；导出时按普通部门 10 元/小时、摄制部 12 元/小时自动计算薪酬，管理员可调整时薪。
- 记录、统计、周报、青传通讯录等工具统一收纳为轻量入口。
- 新增“协作广场”入口，集中放置活动建议、采编办公协同、摄制预约协作等协作范式。
- 采编办公协同支持采编部发起稿件同步需求、办公部部长派发、办公部干事反馈、管理员审核归档；审核通过后会自动核算对应工作量。
- 摄制预约协作支持任意成员预约时间、地点和任务，摄制部部长派发，摄制干事提交完成结果并指定办公部归档成员，归档后自动核算工作量；预约不足配置阈值时工时按加急倍率计算。
- 摄制预约与采编办公协同按流程类型隔离展示；创建表单会按账号带入上一次填写内容，预约发起时必须填写联系方式，并可分别设置到期前提前提醒小时数。
- “我的 -> 工具”提供自动归档工时规则和部门职责划分，工时、时薪和流程关联部门仅管理员可修改。
- “我的 -> 工具 -> 任务提醒”提供微信订阅消息授权；管理员可配置消息模板字段。任务流转和接近 DDL 时会优先推送微信服务通知，同时保留站内通知兜底。
- 用户可在“我的”自助注销账号；管理员可在测试阶段一键清空并重新注入测试账号和演示数据。
- 通讯录支持添加、编辑、删除、复制电话/邮箱/微信号/QQ。
- 活动建议支持提交、管理员审核、创建时间投票、投票、结束投票、活动通知。

## 云数据库集合

`cloudfunctions/api` 首次进入业务功能时会自动创建并补齐这些集合。账号密码登录不会等待全量初始化，以免首次登录超过小程序云函数调用时限：

- `users`：用户账号、角色、部门、微信绑定 OpenID、登录 token、登录过期时间。
- `departments`：部门列表。
- `members`：成员信息。
- `weekly_records`：每周工作记录。
- `contacts`：青传通讯录。
- `suggestions`：活动建议。
- `votes`：投票主题和选项。
- `vote_records`：投票记录。
- `notifications`：活动通知。
- `handoffs`：部门协同流转需求和归档记录。
- `allowance_rules`：自动归档工时、部门时薪及加急设置。
- `workflow_responsibilities`：协作流程关联部门。
- `notification_settings`：微信任务提醒模板及字段配置。
- `notification_subscriptions`：成员对一次性微信订阅消息的授权状态。

推荐在云开发控制台把集合权限设置为“仅云函数可读写”或等价安全规则。小程序端不直接操作数据库，所有权限判断都在 `api` 云函数中完成。

## 部署步骤

1. 用微信开发者工具导入本项目目录（克隆后的本地路径）。

2. 确认 `miniprogram/app.js` 中的云环境 ID 已替换为你自己的：

```js
const CLOUD_ENV_ID = 'YOUR_CLOUD_ENV_ID' // 替换为你的云开发环境 ID
```

> 云开发环境 ID 可在微信开发者工具「云开发」控制台查看。没有云环境时请先开通云开发并新建环境。

3. 在微信开发者工具左侧找到 `cloudfunctions/api`，右键选择：

```text
上传并部署：云端安装依赖
```

4. 部署完成后点击“编译”运行小程序。

5. 到微信公众平台的“订阅消息”中选择一条包含任务名称、任务说明、时间字段的模板，并在“我的 -> 工具 -> 任务提醒”中由管理员填写模板 ID 和实际字段名。字段默认值为 `thing1`、`thing2`、`time3`，需按所选模板调整。成员使用各自已绑定账号的微信授权“开启下一条任务提醒”后，才可接收一次微信服务通知。

6. 普通登录只校验账号并建立会话，不会在登录请求内生成全部演示数据。需要完整测试数据时，先用“测试管理员 / 123456”登录，再到“我的 -> 工具 -> 重置测试数据”执行重建；该操作会清空当前云环境的全部账号、业务数据和配置，再重新注入默认配置和演示账号。请只在测试阶段使用它。正式使用时可先注册正式管理员账号，注册成功后去“我的 -> 人员与部门管理”维护部门、成员和用户角色，再到“工时规则”和“部门职责”完成配置。

## 登录与测试账号

登录流程：

1. 点击“微信授权登录”。
2. 如果当前微信已经绑定账号，会直接登录并刷新 14 天登录态。
3. 任意账号都可输入姓名和密码，点击“账号登录”。这只建立当前设备会话，便于同一测试机切换多个账号，不会改变正式账号已有的微信绑定。
4. 新用户点击“注册并绑定微信”，注册成功后会直接绑定当前微信。

账号密码登录会使用临时设备会话，因此既可切换测试账号，也不会抢占正式账号的微信绑定。微信一键登录仍会按已绑定账号直接登录。

通过“重置测试数据”生成的演示数据包含：

- 当前周多部门工时记录。
- 采编部到办公部与摄制预约协作两套独立需求，分别覆盖待派发、待执行、待归档、已归档等状态。
- 采编办公协同归档后，原创稿件会按工时规则为采编提交人、办公承接人和填写的审核人员生成自动记录；转载稿件只生成办公侧同步工作量。自动生成的工作量仍可由对应部长在工作量维护中调整。
- “兄弟部门”成员只参与摄制预约：可以发起自己的预约并查看流转状态，任务由摄制部部长派发、摄制部干事完成、指定办公部成员归档；看不到采编办公协同和其他人的摄制任务。
- 青传通讯录支持填写职级、届别和宿舍，并可按届别筛选。

采编办公协同建议按这个顺序测试：

1. 用 `采编干事 / 123456` 登录，进入“协作广场 -> 采编办公协同”，可以看到发起采编对接表单并提交报备。
2. 用 `办公部长 / 123456` 登录，在“流转中”给待派发需求选择 `赵六` 或 `钱七`。
3. 用 `赵六 / 123456` 登录，提交同步结果。
4. 用 `管理员老师 / 123456` 登录，在“流转中”审核待审核需求，通过后会自动进入归档。

上线前建议在 `cloudfunctions/api/index.js` 中把 `ENABLE_TEST_ACCOUNTS` 和 `ENABLE_DEMO_DATA` 改为 `false`，并在云数据库中删除测试账号和 `seedTag: demo-2026-09-08` 的演示数据。

## 后续建议

- 在开发者工具中重新部署 `api` 云函数。
- 首次运行后到云开发控制台确认 14 个集合已创建。
- 完整测试：注册管理员、添加部门/成员、注册部长、批量上传、筛选记录、导出周报、通讯录、活动建议、投票。
- 如果此前云环境里已有旧部门集合，不会删除旧部门，只会补齐新版默认部门。
- 如果要迁移本地 SQLite 旧数据，需要单独写导入脚本把 `server/data/app.db` 转入云数据库。
