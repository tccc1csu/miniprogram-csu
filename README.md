# 青年传媒中心工作统计小程序

本项目是微信云开发版本，不需要启动本地 Node/SQLite 后端。

- AppID：`wx4972972007bb6a4e`
- 云环境 ID：`cloud1-d2gd4994t925d1435`
- 小程序前端：`miniprogram/`
- 统一云函数：`cloudfunctions/api/`

## 已整合功能

- 微信授权登录：已绑定账号可一键登录，登录态默认保留 14 天。
- 注册与微信绑定：注册成功后直接绑定当前微信；已有账号可用姓名和密码完成微信绑定。
- 第一位正式管理员可自助注册；测试管理员账号不会占用正式管理员名额。
- 普通成员可自行上报每周工作类型、工作内容和工时；津贴由部长或管理员填写确认。
- 工作量类型固定为：稿件写作、视频制作、美编设计、日常办公。
- 部长批量维护本部门成员每周工作内容、工作量和津贴。
- 上传页显示已填写人数、总工作量、总津贴，并支持一键清空草稿。
- 管理员首页显示部门排名。
- 记录页支持管理员按部门筛选。
- 周报表格支持复制文本周报和 CSV 数据。
- 记录、统计、周报、青传通讯录等工具统一收纳为轻量入口。
- 新增“协作广场”入口，集中放置活动建议、采编办公协同、摄制预约协作等协作范式。
- 采编办公协同支持采编部发起稿件同步需求、办公部部长派发、办公部干事反馈、管理员审核归档；审核通过后会自动核算对应工作量。
- 摄制预约协作支持任意成员预约时间、地点和任务，摄制部部长派发，摄制干事提交完成结果并指定办公部归档成员，归档后自动核算工作量和津贴；预约不足配置阈值时工时按加急倍率计算。
- “我的 -> 工具”提供自动归档津贴规则和部门职责划分，规则和流程关联部门仅管理员可修改。
- 通讯录支持添加、编辑、删除、复制电话/邮箱/微信号/QQ。
- 活动建议支持提交、管理员审核、创建时间投票、投票、结束投票、活动通知。

## 云数据库集合

`cloudfunctions/api` 首次调用时会自动创建并补齐这些集合：

- `users`：用户账号、角色、部门、微信绑定 OpenID、登录 token、登录过期时间。
- `departments`：部门列表。
- `members`：成员信息。
- `weekly_records`：每周工作记录。
- `contacts`：青传通讯录。
- `suggestions`：活动建议。
- `votes`：投票主题和选项。
- `vote_records`：投票记录。
- `notifications`：活动通知。
- `handoffs`：部门协同流转需求和归档记录。
- `allowance_rules`：自动归档工时、津贴规则及加急设置。
- `workflow_responsibilities`：协作流程关联部门。

推荐在云开发控制台把集合权限设置为“仅云函数可读写”或等价安全规则。小程序端不直接操作数据库，所有权限判断都在 `api` 云函数中完成。


5. 部署后首次调用 `api` 云函数会自动创建集合，并注入测试账号与演示数据。正式使用时可先注册正式管理员账号，注册成功后去“我的 -> 人员与部门管理”维护部门、成员和用户角色，再到“津贴规则”和“部门职责”完成配置。
